`monitor:list` shows `last_error: "Script exited with code 1"` which superficially matches the no-op pattern. But:
- The wrapper script (`monitor_list.py`) calls `subprocess.run([sys.executable, str(SCRIPT), "--mode", "check"], ...)`

- The subprocess (`tasks_monitor.py`) fails with HTTP 401 → `refresh_token()` → `invalid_grant`
- **This is a real error, not a no-op.** Classification requires running the script and checking the subprocess error.

**Rule**: Before classifying a monitor script exit 1 as `oc_cron_no_agent_exit_1_noop`, verify the script genuinely has nothing to do by running it manually and inspecting the subprocess error.
